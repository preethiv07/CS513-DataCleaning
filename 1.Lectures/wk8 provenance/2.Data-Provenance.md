1. **Definition** - Provenance is the origin or earliest history of data; includes ownership records and transformation history.
2. **W3C Standards** -	PROV specifications define ontology and data model standards for expressing provenance across systems.
3. **Scientific Domains**	- Provenance spans genealogy, phylogeny, art authentication, and scientific research such as climatology.
4. **Provenance Tools**	- Tools like YW allow annotation of code to make implicit workflows explicit; NW captures Python execution.
5. **Script-Based Provenance**	 - Scripts in R or Python often perform complex workflows; provenance is needed but not embedded by default.
6. **YesWorkflow Capabilities**	- YW enables visual modeling of workflows from script comments without modifying the script logic.
7. **noWorkflow Capabilities**	-NW records provenance automatically from Python code execution and supports filtered lineage analysis.
8. **Example Workflows**	- Use cases include gene expression analysis, paleoclimate reconstruction, and X-ray diffraction pipelines.
9. **DataONE Support**	- DataONE infrastructure captures and utilizes provenance metadata to ensure reproducibility and discovery.
