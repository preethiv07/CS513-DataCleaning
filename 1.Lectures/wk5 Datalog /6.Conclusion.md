## 📚 Details

### 🔸 What We Learned

- We shifted from **pattern matching (syntax)** to **logical integrity checking (semantics)**
- **Datalog rules** express constraints like:
  - **Functional dependencies** (one column determines another)
  - **Inclusion dependencies** (foreign key relationships)

Example:
```
ic_violated(X) :- student(X,Y), student(X,Z), Y != Z.
```

## 🔸 Denial Constraints in Datalog
	•	Denial constraints = rules that describe the bad:
	•	“If this situation exists, it’s an error”
	•	They help pinpoint exactly where data violates logic rules
