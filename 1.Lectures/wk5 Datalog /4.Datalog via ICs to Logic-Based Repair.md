# Lecture: Datalog via Integrity Constraints (ICs) to Logic-Based Repair

## ✅ Summary

This lecture builds on earlier concepts by showing how **Datalog** goes beyond simple queries to express **integrity constraints (ICs)** and even support **logic-based repair** of databases when constraints are violated.

Key takeaways:
- **Datalog as a power tool**: It allows you to define ICs as logic rules and check if a database satisfies them.
- ICs can model:
  - **Key constraints** (e.g., uniqueness of a student ID)
  - **Foreign key constraints** (e.g., every enrollment must link to an existing student)
- Datalog’s **recursion** capability makes it ideal for querying complex structures like **trees** and **graphs**, which SQL struggles with.
- **Answer Set Programming (ASP)** extends Datalog for **repairing databases** when ICs are violated.
  - ASP can generate **alternative repaired versions** (possible worlds) of a database that restore consistency.
- The lecture provides a **high-level overview** of these ideas, laying the groundwork for more advanced topics.

---

## 📚 Details

### 🔸 Datalog for Integrity Constraints

- ICs are written as **Datalog rules**:
  - Example: "No two students can have the same ID but different names."
- These rules are both **checks** and **queries**:
  - You can **detect violations** by running a query.
  - Violations = rows that do not satisfy the constraints.

---

### 🔸 Recursion in Datalog

- Datalog can express recursive queries, e.g.:
  - Finding **paths in graphs** (ancestor relationships, transitive closures)
  - Querying **hierarchical data** like trees

🧠 SQL lacks native recursion support, making Datalog the preferred tool for logic-heavy data tasks.

---

### 🔸 Introduction to Logic-Based Repair

- **ASP (Answer Set Programming)** builds on Datalog, adding:
  - The ability to **define repairs** through disjunctions (logical ORs).
  - Generating **minimal repairs** that restore ICs.
  - Exploring **all possible worlds** (alternative, consistent datasets).

Example:
- A student ID `101` with conflicting names:
  - ASP lets you define a rule that says:  
    "Either John stays, or Joe stays, but not both."

---

### 🔸 Big Picture

| Concept                  | Datalog Capability                     |
|--------------------------|---------------------------------------|
| ICs as Rules             | Yes                                   |
| Checking ICs (Validation)| Yes (via queries)                      |
| Recursion (Graphs/Trees) | Yes                                   |
| Database Repair (ASP)    | Yes (with Answer Set Programming)      |
| Multiple Possible Worlds | Yes (ASP: Disjunctive rules + models)  |

---

> 🧠 Datalog is more than a query language—it’s a logic engine that can detect and even fix relational inconsistencies.
