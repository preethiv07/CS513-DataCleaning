✅ Step-by-Step Guide: Create Private Repo & Add Collaborator

1. Create a Private Repository
	1.	Go to: https://github.com/new
	2.	Fill in:
	•	Repository name: e.g., cs513-data-cleaning
	•	Description (optional): e.g., Data Cleaning project for CS513
	•	Visibility: Select Private
	•	(Optional) Check Add a README file
	3.	Click Create repository

⸻

2. Add Your Teammate as a Collaborator
	1.	Go to the repository page
	2.	Click on Settings (⚙️ tab in the top menu)
	3.	On the left sidebar, go to Collaborators and teams
	4.	Under Manage access, click Invite a collaborator
	5.	Type your teammate’s GitHub username or email
	6.	Click Add [username] to this repository
	7.	Your teammate will receive an email invitation — they need to accept it.

⸻

3. Confirm Their Access
	•	Once accepted, your teammate will have write (contributor) access by default.
	•	They can:
	•	Clone the repo
	•	Create branches
	•	Push commits
	•	Open pull requests

⸻

🧪 Optional: Use SSH or PAT (Personal Access Token) for Authentication
	•	If you’re both using SSH keys, ensure the key is added to your GitHub account:
	•	GitHub SSH key setup
	•	If you’re using HTTPS and 2FA, GitHub will require a Personal Access Token instead of a password.

⸻

🧠 Tip for CS513 Project Collaboration
	•	Create a clear branch naming convention (e.g., feature-cleaning, notebook-validation)
	•	Use README.md to document:
	•	Project overview
	•	Dataset details
	•	How to run the code
	•	Task assignments
